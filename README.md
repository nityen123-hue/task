# Largest Number Finder

## Overview

This is a simple JavaScript project that finds the largest number among three user-entered values.

The program takes three numbers as input using prompt boxes and displays which number is the greatest.

## Features

* Accepts three numbers from the user.
* Compares the numbers using `if-else` conditions.
* Displays the largest number.
* Handles cases where two or more values are equal.
* Simple and beginner-friendly code.

## Technologies Used

* HTML5
* JavaScript

## How It Works

1. Open the project in a web browser.
2. Enter three numbers when prompted.
3. The application compares the values.
4. The result is displayed on the webpage.
